# MemoryGrove
Memory Grove - это специализированный некоммерческий веб-сервис для людей, потерявших память вследствие различных причин.
Эксперты выделяют 4 основные причины потери памяти:
- Неврологические причины:
1) Черепно-мозговые травмы (сотрясения мозга, контузии)
2) Инсульты (ишемический, геморрагический)
3) Нейродегенеративные заболевания (болезнь Альцгеймера, деменция с тельцами Леви, лобно-височная деменция)
4) Эпилепсия и эпилептические приступы
5) Опухоли головного мозга
6) Рассеянный склероз
- Сосудистые нарушения:
1) Сосудистая деменция
2) Транзиторные ишемические атаки (ТАИ)
3) Хроническая ишемия мозга
- Психиатрические причины: 
1) Диссоциативная амнезия (реакция на психологическую травму)
2) Посттравматическое стрессовое расстройство (ПТСР)
3) Депрессия (псевдодеменция)
- Другие медицинские причины:
1) Метаболические нарушения (гипотиреоз, дефицит витамина B12)
2) Инфекции (менингит, энцефалит, нейросифилис)
3) Токсичное воздействие (алкоголь, наркотики, некоторые лекарства)
4) Кислородное голодание (после остановки сердца, удушья)

Веб-сервис является технологическим решением для помощи в реабилитации людям, столкнувшимся с потерей памяти в виду описанных выше причин.
# Модуль веб-сервиса
Предполагаются следующие модули данного приложения:
- Модуль "Безопасный лес":
1) Простые данные о пациенте (ФИО, возраст, город, имя лечащего врача, адрес проживания)
2) Дневник восстановления (личные дневник, недоступный другим пользователям, куда пациент записывает свои мысли, вопросы, чувства - это основа для будущей терапии)
3) Система напоминаний (максимально простые напоминания - принять таблетки, приём у врача и т.п.)
- Модуль "Восстановление связей":
1) Контакты доверия (семья, друзья, коллеги, лечащие врачи)
2) Контролируемое общение (возможность ведения переписки только с подтверждёнными контактами)
- Модуль "Цифровая память":
1) Фотографии с целовеком
2) Список значимых и любимых мест (адрес текущего места проживания, адрес поликлиники, университет, работа, любимый парк и т.д.)
3) Коллекция интересов (списки любимых фильмов, книг, музыки, игр; цель - понять, нравится ли пациенту это сейчас)
4) Анкета навыков (чек-лист, содержищий действия, которые ранее пациент умел совершать)

Дополнительно планируется добавить вкладку "Психологическая помощь", которая либо будет перенаправлять на сайт службы психологической помощи, либо будет содержать контакты центров доверия
# Используемые технологии
Стек, применяемый для разработки веб-сервиса:
1) Backend: Java 24 (JDK Amazon Corretto 24.0.2.12) + Spring Boot 3.5.9
2) Frontend: JavaScript + Node.js (v24.13.1) + Vue 3
3) База данных: PostgreSQL (18.0) + Liquibase + JPA/Hibernate
4) Система сборки: Gradle
